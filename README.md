# Portafolio de Marco Ulises Flores Chona

## Cómo abrirlo
1. Descomprime la carpeta.
2. Abre `index.html` con Google Chrome, Edge o Firefox.
3. Para editarlo, abre la carpeta completa en Visual Studio Code.

## Archivos principales
- `index.html`: contenido de la página.
- `css/style.css`: diseño y adaptación a celular.
- `js/main.js`: animaciones, menú y fondo de partículas.
- `img/perfil-marco.jpeg`: fotografía principal.
