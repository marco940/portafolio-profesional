OCR con Inteligencia Artificial

Sistema desarrollado para procesar imágenes y reconocer texto en placas vehiculares, identificaciones y documentos mediante visión por computadora.

PythonOpenCVTesseractOCR
GitHub del autor Contacto

Problema

La lectura manual de placas y documentos consume tiempo y puede producir errores cuando las imágenes tienen ruido, poca iluminación o perspectivas difíciles.

Solución desarrollada

Se implementó un flujo de preprocesamiento de imágenes con escalado, contraste, binarización y limpieza para mejorar la información antes de enviarla al motor OCR.

Funciones principales

  • Carga de diferentes tipos de documentos
  • Preprocesamiento automático
  • Reconocimiento y limpieza del texto
  • Interfaz para procesar nuevas imágenes

Aprendizajes

  • Tratamiento de imágenes
  • Ajuste de parámetros OCR
  • Validación con expresiones regulares
  • Diseño de interfaces en Python
